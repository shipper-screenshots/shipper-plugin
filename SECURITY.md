# Security Policy

## Supported versions

Security fixes are provided for the latest released version of Shipper Plugin. Upgrade to the latest version before reporting an issue that may already have been resolved.

## Report a vulnerability privately

Use this repository's **Security** tab and select **Report a vulnerability** to open a private GitHub Security Advisory.

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, social post, or other public channel.

Include, where possible:

- the affected Shipper Plugin version and Shipper app version;
- the macOS and Codex versions;
- clear reproduction steps and the observed impact;
- relevant logs with credentials, tokens, personal data, project content, and App Store Connect information removed;
- whether the issue affects the Plugin package, local resolver, bundled helper connection, permissions, or App Store Connect workflow.

You will receive an acknowledgement through the private advisory. Status and remediation details will remain in that private thread until coordinated disclosure is appropriate.

## Scope

Security reports may cover the Shipper Plugin manifest, Skills, local resolver, its connection to the helper bundled with Shipper, and Plugin-initiated Shipper or App Store Connect actions.

For ordinary defects, installation help, or feature requests that contain no sensitive information, use GitHub Issues instead.
